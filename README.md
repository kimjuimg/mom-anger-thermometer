# 엄마 짜증 온도계

아이 때문에 화가 치밀 때, 소리 지르기 전에 1분만 여는 엄마용 웹앱.

👉 **바로 쓰기: https://kimjuimg.github.io/mom-anger-thermometer/**

## 기능
1. **지금 몇 도예요?** — 0~100 슬라이더로 짜증 온도를 재고, 구간별 조언을 보여 줘요.
2. **같이 숨 쉬어요** — 4초 들이쉬고 6초 내쉬기를 4번(40초) 반복해요.
3. **지금 무슨 상황이에요?** — 사춘기 자녀와 자주 부딪히는 상황 6개에 대한 대처 카드.
4. **속풀이 메모** — 하고 싶던 말을 적고, 🔥 태우기로 완전히 지워요.
5. **힘들 때 연락할 곳** — 1388 / 109 / 112

## 개인정보
메모는 브라우저(`localStorage`)에만 저장되고, 어디에도 전송되지 않아요.
